---------- DESCRIPTION ----------
The scripture class will contain a Reference object along with
a list of word objects. It will use these two objects to manage
the reference and the words within the scripture. The Reference
class will format and store the reference itself. The word class
will manage whether the text of each individual word is hidden 
or displayed. A program class will be written to tie these classes
together, along with generating a user interface within the console.
